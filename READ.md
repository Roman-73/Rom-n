# Lavaseco Angiexpress 

Sistema de gestión de órdenes de servicio para Lavaseco Angiexpress.  

## Archivos del proyecto

- `lavanderia_arboles.py` → Código principal del árbol
- `ordenes.txt` → Archivo de órdenes del Corte 1 (datos de ejemplo)

## Cómo ejecutarlo

1. Descarga o clona el repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta:

```bash
python lavanderia_arboles.py
